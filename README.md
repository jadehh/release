# 更新日志

## v2.5.6

* Image支持toCpu方法, 用于将设备上的图像转换为CPU上的图像, 用于调试和分析
* 新增Matcher类, 用于匹配特征点
* 修复OpenCV没有匹配器导致无法编译的问题
* 代码优化, 修复一些警告和错误
* 编译生成需要hidden visibility
* Opencv打开相机需要返回相机的状态,如果相机打开失败,通过回调的函数返回
* Linux上也支持gbk编码的字符串转换为utf-8编码的字符串, 用于处理中文字符
* opencv GPU 解码支持配置GPU ID, 可以指定使用哪个GPU进行解码, 默认使用第一个GPU
* CUDA10 不支持30以上的显卡, 请使用CUDA11以上版本
* 设置GPU ID的时候需要自动判断ID是否有效, 如果无效, 则默认使用第一个GPU
* 添加获取设备数量的方法, 用于获取当前系统上的设备数量, 包括GPU或者NPU设备
