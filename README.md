# 更新日志

## v1.0.6

* 优化时钟同步,如果有chronyd,则使用chronyd同步时间,否则使用NTP同步时间
* 优化拼接管理服务的功能,自动根据生成端口号和和GPU ID
* 优化图片缩放窗口快捷键
* 退出时同时退出app
* 修改docker启动命令,支持所有GPU,使用docker run --gpus all 的方式启动容器,后续需要在低版本的显卡驱动上测试是否正常
* 加密狗支持登录方式,支持系统登录和和网络登录,默认是系统登录模式
* 日志系统完善,执行命令的日志会直接记录哪一行执行的
* 修复切换加速器后,无法运行的bug,切换加速器需要删除安装目录
* 优化箱号识别服务参数详情,介绍参数的作用和默认值
* 日历中每次选择的时候都要更新当天的日期
* 修复拼接参数异常的bug
* 视频拼接管理服务收到相同的通道支持修改通道的配置,并刷新通道
* 多GPU判断,确保每个通道都能合理的分配到不同的GPU
* 算法服务需要判断Device ID 是否满足条件
* Device ID 编辑的时候无法修改,只有在创建的时候才能修改Device ID
* 修复文件下载,如果已经下载过的,不需要重复下载
* 修复远程环境安装界面闪退的问题
* 转发0x21报文需要修改序列号
* 修改CommonConfigWidget,添加Device ID的提示,提示用户在创建的时候才能修改Device ID
* 支持ftp和http协议的图片或视频查看
* 修复了日志窗口中，普通文本意外继承其他行文本颜色导致显示异常的 Bug，提升了日志阅读体验。
* 箱号识别服务支持额外信息的显示,如:危险品标志,箱门额外信息等
* 箱号识别服务支持箱门额外信息的配置,上传模型等功能,这些模型为额外模型,不在通用模型中
* 修复查看实时日志,一直重复最后一行的问题,现在会自动滚动到最新的一行
* 网络测试中，支持删除已配置的网络测试参数
* 修复视频推流中,如果视频格式是mjpeg,则需要添加-c:v=mjpeg参数
* 添加Github的代理地址
* 判断显卡加速类型的时候需要指定显卡的ID
* 为了兼容旧版本,可以不开启主机网络
* 启动过程中,不能进入算法配置详情的界面,只有启动完成后,才能进入算法配置详情的界面
* 加密狗支持使用本地登录和网络登录,默认都是本地登录,网络登录只有测试环境才需要使用
* 新增删除通道数据的功能，只负责停止通道，不删除通道的配置，但是会删除通道的数据
* 更新RtspPushController参数,支持CUDA10和CANN6的硬件解码加速
* 调整箱号修改Api Version触发其他的逻辑。
* 支持更新箱号额外信息识别的模型
