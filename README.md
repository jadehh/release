## 更新时间 
2026-11-13 16:44:15 
# 更新日志

## v1.0.8

* 箱号识别服务支持多GPU推理
* 危险品检测日志优化
* 检测结果规则优化
* 修复危险品检测的bug
* 统一的内存管理,使用QueueManager类,管理所有队列的内存分配和释放,避免内存泄漏
* 代码重构,清理一些冗余的代码
* 危险品检测的结果,跟随着箱号结果一起返回,不在需要通过超时单独的判断返回
* 加入箱门额外信息识别的代码,识别出箱门上的其他信息,比如重量,体积,容积等参数
* 箱门额外信息模型构建推理,支持识别出来的信息解析
* 重量数字归属改用Y 坐标 — 铭牌 KG/LBS 上下分层，按数字与单位 token 的 Y 距离分配，解决之前 X 排序导致分配反的问题。
* 职责分离— extractWeights 只管分配，correctWeightsByConstraint 只管修正（反标检测、不合理值重算、缺失补漏），互不干扰。
* 置信度加权 + 修正降级— 分配阶段用标签 40% + 数字 60% 加权计算 conf；修正阶段凡动过值的条目 conf × 0.5，下游可据此判断是否需要人工复核。
* 一致性校验 — 验证 MGW = Tare + Payload（容差 ±150kg）
* 如果开启箱门额外信息识别,或者开启危险品检测的时候,获取箱号识别结果都需要等待这些信息识别完成,才能返回
* 修复编译测错误
* 支持自适应参数调整,开启箱门识别必须要开启箱门抓拍完整
* 开启箱门抓拍完整,必须要开启过滤集装箱功能
* 开启箱门额外信息识别,需要判断模型是否存在,如果不存在,则报错
* 直接在ContainerEngine中启动加密狗适配器,避免在主线程中启动,导致的性能问题
* 修复内部处理模式的bug
* 修复有顶相机的情况，并且前相机是垂直的箱号，必须要识别对，才认为是单箱号
* 优化顶相机检测代码,通过区域位置筛选出顶相机的图片提高识别准确率
* 内部处理模式的时候,支持直接本地保存箱号识别记录,优化本地保存根据需要保存危险品和箱门额外信息
* 优化资源管理,避免主动退出导致的资源泄漏问题
* 修复前相机识别错，但是总得分很高的问题,重新设计Container打分规则,降低识别错的得分
* 修复本地保存箱号识别记录的问题，避免超时保存
* 修复有识别结果，没有前相机抓拍的图片的情况
* 额外信息识别宽度需要调整为384,在Ascend上图片对齐
* 优化Config配置规则
