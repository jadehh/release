# 更新日志

## v1.0.5

* 视频流协议支持Rtmp和Custom Rtsp协议
* 并支持Custom Rtsp协议的参数和预览功能
* 推流配置参数支持缓存,避免重复配置
* 工具中新增视频拼接服务使用Socket启动,与验残平台通信
* 代码重构,优化代码结构
* 支持与验残平台对接,解析0x15报文,并判断服务器的状态,相机状态,是否需要保存通道配置
* 新增拼接服务的配置界面,支持从0x15报文获取拼接服务的参数
* 拼接服务配置详情界面,支持设置验残平台的IP地址和端口号和自动验残服务的参数
* 支持是否开启自动验残服务的参数和测试功能
* 拼接服务相机新增功能支持添加和删除相机,添加相机支持使用视频相机和线阵相机
* 拼接服务支持添加和删除相机,添加相机支持使用视频相机和线阵相机
* 拼接服务最多支持添加3个相机,完成拼接服务的部署,使用本地部署的方式进行测试,部署拼接服务
* 优化在x86服务器上远程同步时间的功能,保证时间同步的准确性
* 优化和验残平台的交互流程,支持服务器上加速硬件的数量与通道数量的匹配
* 拼接服务可以从验残平台接受配置信息,也可以手动创建通道信息
* 相机预览辅助线支持区分箱号识别服务的顶相机和拼接服务的顶相机
* 不使用自定义Rtsp流协议的时候,自动隐藏房间号
* 推流是支持手动设置倒计时的视频添加,方便测试
* ui框架升级,优化界面,提高用户体验
* 代码清理
