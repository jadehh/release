# 更新日志

## v2.5.8

* 优化加密狗释放逻辑，确保在监听线程先停止, 再释放加密狗, 避免重连线程继续尝试连接
* 相机重连机制优化,初始化的时候相机如果打开失败,也支持重连机制,密码错误的情况下,也会重连,提示密码错误,遇到封禁情况下,需要修改密码
* EIO重连机制优化, 初始化的时候EIO如果打开失败,也支持重连机制。
* 修复Aclite中如果打开相机失败, 会导致异常的问题, 更新华为小站基础的Docker环境,升级Aclite到最新版本
* 解决在Ascend上如果分辨率过高导致无法录像的问题,自动切换录像的分辨率, 以适应Ascend的性能限制
* 相机网络不通与账号密码错误，重连的时间间隔优化，网络不通，重连间隔为30s，账号密码错误，重连间隔为10m
